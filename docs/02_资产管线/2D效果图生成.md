# 2D 高清效果图生成（圣殿骑士）

> 状态：已产出 3 张角色效果图 + 9 张装备单品图 + 2 张拼版｜2026-10-26
> 工具：`tools/gen_effect_2d.py`（生成）、`tools/make_effect_sheets.py`（拼版）

## 1. 定位与边界

这套图是**2D 视觉资产**，用于设定对照、宣发和验收，**不是 3D 模型**，也不替代
`assets/models/characters/templar_tpose.glb`。它与现有 3D 资产的关系：

- 3D 资产负责游戏内运行（GLB / 绑定 / 换装）
- 2D 效果图负责「看起来应该是什么样」的快速对齐
- 两者共用同一套设计语言：白袍 + 单一大红十字、锁子甲、桶盔、鸢形盾、深色披风

## 3. 技术规格

- 模型：MiniMax `image-01`
- 端点：`POST https://api.minimax.chat/v1/image_generation`
- 角色：`width=1536, height=2048`（3:4，高度取 API 上限 2048）
- 装备：`1536×1536`
- 落盘：JPEG quality 95；最终成图另存 PNG（无损封装）
- 关闭 `prompt_optimizer` 与 `aigc_watermark`，保证 prompt 可控、无水印

**尺寸踩坑**：`width/height` 上限标称 2048，但 `2048²`（4.19 MP）和 `1792²`（3.21 MP）
都会触发服务端 60 秒 RPC 超时；`1536²`（2.36 MP）稳定通过。角色 1536×2048 也可稳定生成。
所以装备统一用 1536²，没有强行上 2048²。

## 4. 生成流程

### 4.1 无甲 T-pose（seed 454）

- 纯文生图，不加角色参考图（参考图会把已有盔甲一起带回来）
- 13 个 seed 里挑出 `454`：双臂接近水平、手掌朝下、面部和身形完整，且没有护腕/护臂
- 无甲造型刻意保持在「内衣层」：亚麻长袍、布腰带、羊毛裤、皮靴，不出现锁甲/头盔/盾/剑

### 4.2 有甲 T-pose（seed 504）

- 纯文生图。**不要用无甲图做 `subject_reference`**：实测参考图会把露脸、手臂下垂的姿势
  一起锁死（见 `drafts/armored_ref_s801/s802`）
- 头盔描述必须写死「faceless / no face / no skin / no eyes」，否则模型一定给一张人脸
- 16 个有甲 seed 中只有 `504` 双臂完全水平；其余大多落成 A-pose（`601/603/612/613/701/702` 等）
- 这一版头盔是**尖顶 sugarloaf 变体**，不是设定里的平顶桶盔；装备图 `01_great_helm` 也按同一
  尖顶造型出图，保证角色与单品对得上
- 另有一版 `drafts/armored_fix_s1002` 是平顶桶盔 + 单十字，但手臂下垂成 A-pose，未作为主图

### 4.3 全套装备英雄图（seed 902）

- 在「有甲」基础上加鸢形盾、改成 3/4 站姿，不再要求 T-pose
- 用来展示盾 + 剑 + 披风 + 罩袍的组合关系，作为宣发/封面候选

### 4.4 装备单品（9 张）

- 统一暗炭灰无缝背景、单侧柔光、轻微接触阴影，模拟博物馆产品摄影
- 每件单独 prompt，强调材质（拉丝钢 / 铆接锁环 / 油浸皮革 / 粗毛呢 / 亚麻）
- 返工记录：
  - 头盔前两版生成成了「鼻甲盔 / 圆顶盔」，改为「像钢桶、平顶、只有两条横眼缝」后得到尖顶桶盔
  - 佩剑第一版剑格缺失，第二版补了「wide straight crossguard」后可用
  - 手套第一版只有一只，改成「pair, both gloves side by side」后得到一对
  - 鸢形盾第一版十字偏花饰，第二版反而生成成椭圆盾，最终保留第一版（轮廓正确优先）

## 5. Prompt 策略（可复用）

1. **T-pose 要写成几何约束**：肩膀 / 肘 / 腕在同一条水平线上、手臂与脊柱成 90°、
   掌心朝下、手指并拢。只写「T-pose」模型会自由发挥成 A-pose。
2. **不要用「尺子/横杆」类比**：`a ruler laid from fingertip to fingertip` 会让模型真的画一根
   木尺/金属杆穿过肩膀（见 `drafts/unarmored_s707/s808`）。
3. **有甲版把「无脸」写在最前**：`completely faceless` + `no face, no skin, no eyes`。
4. **红十字限定数量**：`exactly ONE cross on the chest, no cross on the skirt`；否则容易在裙摆
   再长一个十字（当前 `02`/`03` 仍有此问题，见第 6 节）。
5. **参考图只用于「换装」不可行**：`subject_reference` 会保留参考图的姿势和露脸，不适合
   「无甲 → 有甲」的加甲流程。

## 6. 已知问题 / 下一轮可修

| 问题 | 影响 | 建议 |
|---|---|---|
| 有甲图罩袍出现**两个红十字**（胸口 + 裙摆） | 与「只有胸前一个十字」的设定冲突 | 用局部重绘（inpaint）抹掉裙摆十字，或换 seed 重出 |
| 头盔为**尖顶**而非设定里的平顶桶盔 | 与 3D 模型 / 概念设定不完全一致 | 以 3D 平顶桶盔渲染图做参考再生成，或直接手绘修正 |
| 腰带单品更像**皮绳盘绕** | 与宽皮带 + 方扣的设定有差距 | 换「wide flat strap, large square buckle」重出 |
| 鸢形盾十字偏**花饰** | 设定要求直臂十字 | 保留轮廓，后期把十字改为直臂 |
| 装备图为 1536²，不是 4K | 大幅面印刷略欠 | 需要 4K 时用 Real-ESRGAN / EDSR 2× 放大，或等 API 支持更大尺寸 |

这些都属于「2D 概念图」的可接受误差；如果这套图要进正式宣发，建议优先修「双十字」和
「头盔形状」两项。

## 7. 复现与重新选图

```bash
# 无甲 T-pose（多 seed 候选）
python3 tools/gen_effect_2d.py unarmored 454 505 606

# 有甲 T-pose（不要加 --ref，参考图会锁姿势）
python3 tools/gen_effect_2d.py armored 504 601 602

# 单件装备（可只指定某一件）
python3 tools/gen_effect_2d.py gear great_helm
python3 tools/gen_effect_2d.py gear

# 选定候选 → 正式图
python3 tools/gen_effect_2d.py final unarmored_s454 01_templar_tpose_unarmored

# 重新拼版 + manifest
python3 tools/make_effect_sheets.py
```

> 注意：`gen_effect_2d.py` 的 seed 只能保证「同参数同 seed」可复现；模型侧仍可能因版本更新
> 产生差异。正式图请连同 `final/*.json` 里的 prompt 一起归档。

## 8. 与 3D 管线的衔接

- 无甲图可直接作为**绑定/蒙皮姿态基准**的 2D 对照（比例 7.5 头身、手臂水平）
- 有甲图可作为 3D 换装部件的**材质/比例参考**（锁甲袖长、罩袍下摆、披风开口）
- 装备单品图可作为 3D 道具的**贴图与造型参考**；`01_great_helm` 目前是尖顶变体，3D 仍以
  `docs/02_资产管线/Blender资产管线.md` 的平顶桶盔为准

python3 tools/make_kit_sheet.py

**这一轮新增的三条硬约束**（都在实践中踩过）：

1. **prompt 必须 < 1500 字符**。`gen_effect_2d.py` 的长 prompt 直接报 `2013 invalid params`；
   本脚本把约束压缩成短句并打印长度自检。
2. **参考图会把「裸头」一起锁死**。直接拿无甲 T-pose 当 `subject_reference`，模型宁可违反
   prompt 也不肯戴盔（正面例子见 `drafts/knight_s1201`，反面见 `knight_s1202` 的闭盔）。
   解法：先把参考图的头部区域涂成中性灰（`masked_ref()`），头部装备才会重新生成。
3. **T-pose 是抽卡，不是指令**。同一 prompt 下约 1/3 的 seed 手臂水平，其余落成 A-pose 或
   双手交握；正式图都是 3–4 个 seed 里挑的，挑选标准写进 `final/*.json` 旁边的说明即可。

已知偏差与下一轮要修的：02 的裙摆十字、03 的胸前浅色布片（军士不该有白）、04 缺弓。
