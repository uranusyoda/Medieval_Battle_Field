# 动作索引站

一个本地静态页，用来逐个 / 并排查看 `templar_rig.glb` 里的四套动作，并对照查看各模型的**骨骼状况**（已绑骨 / 未绑骨、骨骼数、蒙皮数、动作数）。不依赖打包工具，three.js 已 vendored 到 `site/vendor/`，断网也能开。

## 启动

```bash
./tools/serve_site.sh          # 默认 8765
./tools/serve_site.sh 9000     # 指定端口
```

打开：

| URL | 内容 |
|---|---|
| `http://127.0.0.1:<port>/site/` | 单动作视图（默认 `templar_rig`） |
| `?grid=1` | 四联视图，四套动作同时播 |
| `?clip=run` | 直接选中某个动作（`walk` / `run` / `jump` / `crouch`） |
| `?model=templar_tpose_unarmored` | 直接打开未绑骨的静态高模 |
| `?model=templar_tpose_unarmored_rigged` | 直接打开绑骨版 |
| `?model=templar_tpose_unarmored_parts_rig_handfix` | 直接打开分块手部修订版（55 骨 / 16 部件） |

> 服务的根目录必须是**仓库根**，因为页面用 `../assets/models/characters/templar_rig.glb` 取模型。直接双击 `index.html` 会被 CORS 拦住（`file://` 下 fetch 二进制不行）。

## 功能

- 左侧动作表：帧数、时长、是否可循环、一句动作说明；点选或按 `1`–`4`
- 时间轴可拖动，播放/暂停（空格），速度 0.25×–2×
- 循环开关（`L`）：关掉后 jump 只播一次并停在最后一帧
- 骨架显示（`S`）：叠一层 `SkeletonHelper`，检查骨骼朝向
- 四联视图（`G`）：同一个 renderer 用四次 `setViewport` 分屏，每格一个 `SkeletonUtils.clone` 的克隆，各自跑一条 clip —— 不用开四个 WebGL 上下文
- 相机：OrbitControls 阻尼、限制俯角不穿地、`R` 复位

## 模型库与骨骼状况

左栏「模型 · 骨骼状况」列出 `site/app.js` 里 `MODELS` 注册的模型，每张卡片带一个状态芯片（`已绑骨` 绿 / `未绑骨` 橙），下面是**实测**出来的骨架、骨骼、蒙皮网格、动作四项。点卡片或按 `M` 切换。

| 模型 | 骨骼 | 蒙皮 | 动作 | 说明 |
|---|---|---|---|---|
| `templar_rig` | 25 | 1 / 1 | 4 | 有甲游戏网格，walk / run / jump / crouch |
| `templar_tpose_unarmored` | 0 | 0 / 1 | 0 | 无甲 Tripo 高模，**未绑骨**，只能看造型与比例 |
| `templar_tpose_unarmored_rigged` | 20 | 1 / 1 | 0 | 上面那个的副本，**绑骨版**：只绑大关节、手为整体，动作还没做 |
| `templar_tpose_unarmored_parts_rig_handfix` | 55 | 16 / 16 | 0 | **分块 · 手部修订版**：左右五指各 3 节，已修订手腕与手指蒙皮，可开启骨架查看 |

数字不写死在卡片里，而是模型载入后从场景图数出来（`isBone` 去重、`isSkinnedMesh` 计数），所以换了 GLB 也不会对不上。没有动作的模型分两种状态：

- **未绑骨**（`templar_tpose_unarmored`）：动作列表给「无动作」占位，播放 / 进度条 / 速度 / 四联 / 骨架 / 循环**全部** `disabled`，HUD 标 `STATIC · UNRIGGED`，底部「静态模型 · 未绑骨 · 无动作」，只留视角。
- **已绑骨但没动作**（`templar_tpose_unarmored_rigged`）：骨骼和蒙皮是在的，所以**骨架开关保留可用**（`S` 能叠 SkeletonHelper 看骨骼），其余照旧停用；HUD 标 `RIGGED · NO CLIPS`，占位文案写「骨架与蒙皮已就位（N 骨 / 1 蒙皮网格），但 GLB 里还没有 animation」。

切回有动作的模型会自动恢复。

切模型时会 `dispose` 掉旧模型的 geometry / material / texture，否则每切一次涨几十 MB 显存（高模贴图 3×4096）。

## 文件

| 文件 | 作用 |
|---|---|
| `site/index.html` | 页面结构 + importmap（`three` → `./vendor/three.module.js`） |

## 自检

用 CDP 驱动真实 Chrome 跑一遍交互（需要 Chrome 开 `--remote-debugging-port=9222`）：

```bash
node tools/check_site.mjs
```

覆盖：模型加载、动作条数、点击切换、四联开关、HUD 隐藏、播放/暂停、暂停后时间不推进、时间轴拖动、骨架开关、速度切换；模型库两条、已绑骨模型 25 骨 / 1 蒙皮 / 4 动作、未绑骨模型实测 0 骨 0 蒙皮、控件停用与「无动作」占位、切回恢复；控制台无报错。共 30 项。

## 注意

暂停状态下切换动作或开关四联视图时，要手动 `mixer.update(0)` 求值一次。原因是 `AnimationMixer` 只在 `update(dt)` 时把 action 写进骨骼；暂停时 `timeScale=0`、主循环不再调用 update，旧 action 已经 `stop()`，模型就退回 bind pose（T-pose）。`selectClip()` 与 `setGrid()` 里都补了这一次求值。

未绑骨模型没有 `mainMixer`、也没有 `cells`，所以 `selectClip()` / `setGrid()` / `togglePlay()` / 键盘 `1`–`4`、`G`、`S` 都要先判空或看 `disabled`，否则切过去立刻报错。
