# 动画与骨骼展厅

基于 60 骨人体结构绑定版制作 8 套动画，集中展示全身步态、跳跃、下蹲、握持及手腕活动。

## 打开 HTML

在项目根目录双击 [查看全部动画.command](../../查看全部动画.command)。启动器会复用已有项目服务，或启动本地服务后打开页面。

也可手动运行：

```sh
./tools/serve_site.sh
```

打开 [动画展示页](http://127.0.0.1:8765/site/anatomical.html)。页面源文件是 [site/anatomical.html](../../site/anatomical.html)。

HTML 使用同目录本地脚本及模型资源，需要通过 HTTP 服务加载三维模型；直接双击 HTML 时会显示启动指引，绑定图片仍可查看。所有资源都在项目内，无需外部 CDN。

动作按 **60 FPS** 烘焙到 GLB 中。行走和奔跑采用原地循环，适合在查看器中对比；进入游戏后应由角色控制器负责整体位移。

### 行走 / 跑步修订（2026-10-27）

根据反馈收窄步宽，修正原先离地及循环边界的速度突变、腿长超限时的膝盖跳变，并让骨盆、肩膀和手臂保持协调。跑步改为闭合握拳。

行走与跑步使用 [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/) Subject 35 的 `35_01`、`35_18` 数据，按角色比例重定向，重新拟合周期曲线，保证循环位置与速度连续。原始动作和来源说明见 [CMU 来源记录](../../assets/mocap/cmu/README.md)。

正面查看腿部：[行走 · 正面](http://127.0.0.1:8765/site/anatomical.html?clip=walk\&view=front#exhibit)；侧面查看重心与摆臂：[跑步 · 侧面](http://127.0.0.1:8765/site/anatomical.html?clip=run\&view=side#exhibit)。

骑士站姿与摆臂继续调整：呼吸待机、行走、奔跑均保留低肩，增加自然腋下空间，让厚袖角色也能看到放松的手臂轮廓。行走时轻屈肘、前臂手腕错相跟随，五指渐进松握；奔跑时肘部在身体外侧，拳头顺势靠内摆动。待机保持胸口舒展和中立头位，加入胸腔呼吸、微小重心转移与双臂不同步的跟随。腿部窄步线、循环节奏和跑步握拳保留。[查看骑士行走](http://127.0.0.1:8765/site/anatomical.html?clip=walk\&view=three#exhibit)。

[修订前连续性测量](../../assets/renders/parts/animated/gait_before.json) · [修订后连续性及步宽测量](../../assets/renders/parts/animated/gait_continuity.json)。

根据腋下截图再次扩大待机、行走和奔跑的双臂空间，同时保持低肩、自然肘弯和腕部跟随。最新测量见 [舒展手臂与忍者低姿验收](../../assets/renders/parts/animated/ninja_style.json)。[此前骑士姿态与跳跃验收](../../assets/renders/parts/animated/athletic_style.json)及[行走肩臂验收](../../assets/renders/parts/animated/knight_walk_style.json)保留作过程记录。

### 忍者低姿

将下蹲改为潜行准备姿势：双脚前后错开，前腿支撑，屈髋降低重心并适当前倾，头部保持向前警觉；前手探出、后手侧收，双臂错开维持平衡。低姿保持片刻后回到站姿，形成三秒循环。[查看忍者低姿](http://127.0.0.1:8765/site/anatomical.html?clip=crouch\&view=three#exhibit)。

### 弹性跳跃

重做两秒原地跳跃：先下压并向后摆臂，再快速伸髋伸膝蹬地；腾空段使用连续重力抛物线，左右腿适当错开、屈膝收腿，双肘弯曲参与平衡；落地后屈髋屈膝吸收冲击，再回弹站稳。空中不再按收腿后的脚底高度追踪整个角色，避免收腿时身体被额外抬高。

动作方向参考 [育碧《刺客信条：影》官方跑酷介绍](https://www.ubisoft.com/en-us/game/assassins-creed/news/4TA6gKaTvtOC1mOjZIxCZd)中强调的动量衔接、不同角色的力量差异与落地缓冲；本项目自行编排骨骼曲线。[查看跳跃](http://127.0.0.1:8765/site/anatomical.html?clip=jump\&view=side#exhibit)。

## 页面操作

- 选择动作，播放 / 暂停，拖动时间轴，调整 0.25×—2× 速度。
- 全身、正面、侧面和双手视角；拖动旋转、滚轮缩放。
- 开启骨架查看关节，或选择「全部同屏」同时播放 8 套动作。
- 手部动作自动使用手部特写；同屏标签可点击返回对应动作。
- 9 张绑定验收图可分类筛选，点击放大。
- 快捷键：空格播放 / 暂停，`S` 骨架，`G` 同屏，`1`—`8` 切换动作。
