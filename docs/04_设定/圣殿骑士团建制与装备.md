# 圣殿骑士团 · 建制与各阶层装备

> 研究简报｜2026-10-26｜用途：给「同一角色按阶层上装备」提供史实依据与美术取舍
> 配套产出：`assets/concept/hd_effect/kit/`（骑士兄弟 / 军士兄弟 / 突厥轻骑 三套装备图）
> 生成脚本：`tools/gen_templar_kit.py`

## 0. 一句话结论

圣殿骑士团不是「一群穿白袍的骑士」，而是一个**有三层兄弟等级 + 一层辅助骑兵**的修道军事修会：
**骑士兄弟（白袍）**、**军士兄弟（黑/褐袍）**、**神父兄弟**，外加**突厥轻骑（turcopole）**。
三兄弟等级都佩**同一枚红十字**，区别在**袍色、甲重、马匹数和兵器**——这正是做「同角色换装」
时最该抓住的分层变量，而不是给每层堆不同的花纹。

## 1. 时间轴与制度来源

| 时间 | 事件 | 对装备的意义 |
|---|---|---|
| 1118/1119 | 于耶路撒冷圣殿山成立，最初 9 名骑士 | 起步即重装骑兵，装备沿用西欧封建骑士制式 |
| 1129 | 特鲁瓦会议（Council of Troyes）承认修会，颁**拉丁规则 72 条**（传为圣伯尔纳铎参与） | 规则同时管「信仰」与「穿什么、带什么」，装备第一次被写进修会法 |
| 约 1138 | 规则译成法文并扩充 | 出现更细的军械、马匹、帐篷、驮兽条款 |
| 13 世纪 | 法文规则扩至 **609 条** | 覆盖等级、司法、出征序列、装备发放与点验 |
| 1139 | 神父兄弟成为正式等级 | 修会内出现「不作战的兄弟」 |
| 1312 | 教宗克雷芒五世解散修会 | — |

规模：鼎盛期约 **15,000–20,000 人，其中真正骑士约十分之一**——所以「军士 + 轻骑 + 侍从」
才是修会的兵力主体，做游戏单位时不要只做骑士。

## 2. 建制树（谁管谁）

```
大团长 Grand Master（终身）
├─ 总管 Seneschal            第二号人物，代行职权
├─ 元帅 Marshal             最高军职：马匹、军械、出征序列、战阵编组
├─ 长官 Preceptor/Commander 行政与补给；地方会所（commandery / preceptory）长官
├─ 衣袍官 Draper            制服与装备的发放、点验（"谁穿白袍"由他管）
├─ 财务官 Treasurer         金银与汇兑（圣殿骑士团的银行职能）
├─ 突厥骑兵统领 Turcopolier  统辖轻骑与辅助部队，战时接管军士/轻骑
├─ 神父长 Prior             总部教堂与圣事
└─ 巡察使 Visitors-general   大团长特派，巡视各行省、纠正弊端
    └─ 行省 Master（法国/英格兰/耶路撒冷/安条克/的黎波里/西班牙/葡萄牙/意大利/匈牙利…）
        └─ 会所 Commander（地方城堡、庄园、码头）
```

要点：**军政分离**——元帅管打仗，长官管吃饭与补给，衣袍官管穿什么，财务官管钱。
「骑士 / 军士」是**身份等级**，上面这套是**职务**，两套体系交叉（军士也能当会所长官，
阿卡港的总管就是军士出身，还兼舰队司令）。

## 3. 四个阶层与装备对照

### 3.1 骑士兄弟（Knight Brother / *frère chevalier*）

- **出身**：贵族，入团前已经是骑士（修会本身不举行授骑士礼）
- **识别色**：**白袍 / 白披风 + 胸前红十字**（白色＝纯洁，是骑士专属，军士无权穿）
- **编制**：重装骑兵，**3–4 匹马 + 1–2 名侍从**（侍从一般不是修会成员，按期限雇佣）
- **防护**：及膝长袖锁甲袍（hauberk）+ 锁甲头巾（coif）+ 锁甲裤（chausses）+ 锁甲手套；
  内衬厚棉甲（gambeson）；12 世纪戴**锥形鼻甲盔**，约 1200 年后换**平顶大桶盔**（great helm）
- **进攻**：长矛（冲锋）、直刃单手剑、钉头锤（破甲副兵器）、匕首
- **盾**：12 世纪**鸢形盾**（kite shield，肩到胫），13 世纪后期改**三角盾**（heater）
- **坐骑**：destrier 战马，13 世纪起加马甲（shaffron / peytral）

### 3.2 军士兄弟（Sergeant Brother / *frère sergent*）

- **出身**：非贵族；铁匠、石匠、会计等手艺人与行政人员多出自这一层
- **识别色**：**黑或深褐袍 + 同一枚红十字**（这是「不是骑士」的第一眼信号）
- **编制**：在圣地编为**轻骑兵，一人一马**；资深军士可带侍从、可配更重的甲
- **防护**（与骑士的关键差别，直接可做美术分层）：
  - **无袖**锁甲袍——便于用弩/弓，前臂裸露或只穿亚麻
  - 锁甲裤**不带脚部包覆**，方便下马步战
  - 内衬**皮/棉软甲**
  - 头盔偏**铁壶盔（kettle hat / *chapeau de fer*）**：牺牲面部防护换视野，利于射击
- **进攻**：长矛、剑、**弩/弓**（修会会专门为军士采购「土耳其式兵器」即弓与轻装）
- **马**：只有很少数高级军士能配一匹以上

### 3.3 神父兄弟（Chaplain Brother）

- 1139 年起设立，司铎身份，**不作战**
- 着装为修会袍 + 红十字，无锁甲；随军负责圣事、临终与记录
- 做单位时是「治疗/鼓舞」位，不是战斗位

### 3.4 突厥轻骑（Turcopole）

- 名称源自希腊语「突厥之子」，原为拜占庭的轻骑弓手，十字军照搬
- 拉丁王国里逐渐泛指「基督徒轻装骑射手」，**不必然是突厥血统**
- **无锁甲**：厚棉甲（aketon）、皮甲、软帽 + 轻盔
- **兵器**：复合弓 + 箭袋、轻剑、标枪；主打侦察、袭扰、追击
- 数量极大——12 世纪一些战例里占骑兵的一半甚至更多；统领 Turcopolier 是高位职务
- 13 世纪起成为修会内的**正式等级**

### 3.5 侍从与雇佣（非成员）

骑士的 squire、弩手、工匠、水手多为按期限雇来的外人，不穿修会袍、不佩红十字。
做「营地/后勤」场景时用这一层补人气。

## 4. 一张表看懂「同角色怎么换装」

| 变量 | 骑士兄弟 | 军士兄弟 | 神父兄弟 | 突厥轻骑 |
|---|---|---|---|---|
| 袍色 | **白** | **黑/深褐** | 黑/褐 | 无罩袍（棉甲本色） |
| 红十字 | 有（胸前） | 有（胸前） | 有 | 无 |
| 躯干甲 | 长袖锁甲 + 棉甲 | **无袖**锁甲 + 皮/棉甲 | 无 | 棉甲/皮甲 |
| 腿甲 | 锁甲裤 + 皮靴 | 锁甲裤（无脚套） | 无 | 无 |
| 头盔 | 锥盔 → **平顶大桶盔** | **铁壶盔** | 无 | 软帽 + 轻盔 |
| 主兵器 | 长矛 + 剑 + 钉头锤 | 长矛 + 剑 + **弩/弓** | 无 | **弓** + 轻剑 |
| 盾 | 鸢形盾 → 三角盾 | 小盾/无 | 无 | 小圆盾/无 |
| 马 | 3–4 匹 | 1 匹 | 0–1 | 1 匹（轻马） |
| 剪影关键词 | 白 + 桶盔 + 大盾 | 深色 + 宽檐盔 + 弩 | 长袍 + 十字 | 弓 + 箭袋 + 轻装 |

## 5. 规则里的「减法」——比加法更重要

圣殿骑士团的识别度来自**限制**，不是装饰：

1. **白袍只给骑士**。军士穿白＝越级，是史实错误，也是设定错误。
2. **十字只在前胸一枚**，直臂式（croix pattée 的简化版）；裙摆、背部、盾面不要到处长十字。
3. **禁金银装饰**：马刺、剑带、马具不许镀金镀银，禁止彩色布料与毛皮——修会要靠「穷」立身。
4. **不做板甲**：板甲是 14 世纪以后的事；12–13 世纪是**锁甲 + 罩袍**的时代。
5. **头盔按年代分**：12 世纪锥形鼻甲盔露脸，1200 年后平顶大桶盔完全不露脸。

### 6.3 换装槽位建议

`helm / coif / hauberk / surcoat(含十字) / belt / sword+scabbard / boots / cloak / shield`

- **surcoat 的十字做成独立小平面**，换阵营只换这一张
- **头盔与袍色是阶层开关**：白袍 + 闭盔＝骑士；深褐袍 + 铁壶盔＝军士；棉甲 + 软帽＝轻骑
- 剑、盾留在道具槽，T-pose 模型本身不带武器（本次四张图都已清空双手）

### 6.4 生成方法与已知偏差

`tools/gen_templar_kit.py`（MiniMax `image-01`，`subject_reference` 指到无甲 T-pose）：

- **prompt 上限 1500 字符**，超了直接报 `2013 invalid params`
- **参考图会连裸头一起锁死**：直接喂原图，模型拒绝戴盔。做法是把参考图的头部涂成中性灰再喂
  （脚本内 `masked_ref()`），头部装备才会按 prompt 生成
- **T-pose 靠 seed 抽**：同一 prompt 下约 1/3 的 seed 能给到水平手臂，其余落成 A-pose；
  正式图都从 3–4 个 seed 里挑
- 已知偏差：02 的红十字延伸到了裙摆（设定要求只有胸前一枚）；03 的胸前有一块浅色布片，
  严格说军士不应有白色；04 没有画弓，只有箭袋
