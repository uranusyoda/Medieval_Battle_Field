## 2. 设计逻辑（为什么这样定）

圣殿骑士的可识别性不靠细节，靠**四个剪影要素**。收敛到这四条，任何距离都能认出来：

1. **白袍 + 红十字** —— 唯一高饱和色，视线第一落点；其余全部低饱和，形成强对比
2. **大桶盔（great helm）** —— 平顶圆柱 + 横向窄眼缝，无面部，天然去个性化、适合量产单位
3. **鸢形盾** —— 上宽下尖的三角轮廓，与头盔的方块形成形状对比
4. **深色罩袍/披风** —— 压住整体的白，避免角色变成"一块白纸"

历史取舍：不做板甲（板甲是 14 世纪后的事），主体用**锁子甲 + 罩袍**，符合 12–13 世纪圣殿骑士的史实；十字为胸前大十字（croix pattée 的简化直臂版），不加纹章碎装饰。

## 3. 配色（可直接用于材质）

| 部位 | 色值 | 材质 |
|---|---|---|
| 罩袍白 | `#DDD6C6`（做旧米白，非纯白） | 亚麻织物，粗织纹 |
| 十字红 | `#9E2B25`（暗朱红，非荧光红） | 手绘颜料，边缘磨损 |
| 锁子甲 | `#5A5E63` | 拉丝钢，高频法线 |
| 头盔 | `#6E7278` | 拉丝钢，轻微凹痕与划痕 |
| 皮革（腰带/靴/剑鞘） | `#4A3527` | 油浸皮革 |
| 黄铜（带扣/剑首） | `#8A6E3C` | 氧化黄铜，粗糙度偏高 |
| 披风 | `#2B2724` | 粗毛呢 |

关键约束：**整张画面只有红十字是高饱和**。一旦给披风加红、给盾加金边，识别度立刻崩塌。

## 4. 比例（转面图实测，单位：头身）

- 总高 **7.5 头身**（半写实，非写实 8 头身，也非 Q 版）
- 肩宽 **2.2 头**，头盔高 **1.15 头**
- 罩袍下摆到小腿中段（膝下约 0.35 身高处）
- 盾高约 **3.2 头**，宽约 **2.0 头**
- 腰带位于身高 **0.58** 处

## 5. 建模参数建议（下一步）

| 项 | 建议值 | 理由 |
|---|---|---|
| 三角面预算 | 主体 **6k–9k tris** | 同屏多单位（自走棋战场最多 8v8），需要能批量实例化 |
| 贴图 | 单张 **2048²** PBR 图集（albedo / normal / roughness-metal 合并） | 一张图覆盖全身，减少 draw call |
| 骨骼 | **21–25 根**（含斗篷 2 根、盾挂点 1） | 与项目其他角色资产维持同一量级 |
| 分离部件 | 头盔 / 盾 / 剑 / 披风 各自独立 mesh | 便于后续换装与武器替换 |
| LOD | LOD0 9k → LOD1 3k → LOD2 800（远处只保留剪影） | 战场视角会同时出现多个单位 |

three.js 落地要点（与当前战斗原型一致的路线）：
- 材质全用 `MeshStandardMaterial`，头盔/甲 `metalness 0.9 / roughness 0.45`，布料 `metalness 0 / roughness 0.95`
- 红十字**不画在贴图上做主体**，而是独立小平面叠在罩袍前（后续换阵营只需换这一张）
- 光源沿用现有三光源（主光暖 + 侧后冷蓝轮廓光），保证与战场其他单位一致

## 7. 明确不做（避免过度设计）

- 不加面部（大桶盔本就无面）
- 不加纹章旗帜、羽毛、金饰、宝石
- 不做披风物理（除非后续上 Rapier，否则用 2 根骨骼做摆动）
- 不做血迹与战损贴花（保持"干净的单位"便于识别阵营）
